个人博客出现的问题及解决

2026年7月29日，我花了大半天时间，只为把第二篇文章发布到博客上。从404到首页不显示，从文件丢失到网络超时，这篇文章记录了我遇到的所有问题和解决办法 一、坑一：文章发布后，首页不显示 *问题现象： 执行完 hugo 和 git push 后，访问博客首页，只能看到第一篇文章，第二篇文章没有出现 *排查过程： 第一步，检查 content/posts/ 文件夹里是否有第二篇文章的文件 ls content/posts/ 文件存在，说明没有丢失 第二步，检查文章的 draft 状态 notepad content/posts/build-blog-notes.md 查看文件开头的 draft 字段（如果是 true，Hugo 就不会生成它，必须改成 false）但是已经被我改成false了，这里没问题 第三步，检查 public/posts/ 文件夹 ls public/posts/ （如果没有第二篇文章对应的文件夹，说明 hugo 命令没有正确生成它）显示找不到该文件夹 *解决办法： 确保 draft: false 后，重新执行： hugo --minify --cleanDestinationDir 然后再检查 public/posts/，才确认生成了文章文件夹 二、坑二：主题文件夹丢失 *问题现象： 执行 hugo 时，报错说找不到布局文件 WARN found no layout file for "html" for kind "home" *原因分析： themes/PaperMod 文件夹被清空或不存在了，我怀疑是在 main 分支和 gh-pages 分支之间切换时，文件被覆盖或丢失了 *解决办法： 重新把主题文件夹放回 themes/ 目录 第一步，确认主题文件夹是否存在 ls themes 发现 PaperMod 是空的，又需要把它重新放进去 ...
